## Publishing rules

- Do NOT commit source PDFs or `private/chemistry_index.json`, extracted pages, scanned covers or debug secrets.
- References in a public app can display bibliographic metadata and original explanations written by the team. If you want to publish full textbooks/chunks, obtain authorization and document it here.
- The private index (`scripts/build_private_index.py`) extracts PDF text only for a locally selected search session. It does not create a publicly deployable RAG database.
- Inference may transmit user-entered questions and selected PDF excerpts to cloud-hosted models; the app requires an explicit consent action for this workflow, but you must still comply with source terms.
- Check the underlying PDF for each cited page. Quran verses/hadith/tafsir citations require separate independent validation; do not present AI speculation as scripture.
- Author original study lessons, worked exercises and explanations. Treat the science and religious perspectives as separate evidence layers.
